# MeaLab

Plataforma colaborativa para descubrir, crear y planificar recetas según ingredientes disponibles, presupuesto y preferencias del usuario.

## Alcance

La plataforma permite a los usuarios:

- Buscar recetas utilizando filtros por ingredientes, tipo o dificultad.
- Crear y publicar recetas culinarias.
- Guardar recetas en colecciones favoritas.
- Planificar menús semanales.

## Tipos de usuarios

- Chef o experto culinario
- Usuario regular

## Tipos de commits

**feat**: nueva funcionalidad  
**fix**: corrección de errores  
**docs**: cambios en documentación  
**style**: cambios de formato  
**refactor**: mejora del código sin cambiar funcionalidad
