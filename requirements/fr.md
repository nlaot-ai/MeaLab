# Requerimientos Funcionales

RF1 – Registro de usuarios  
El sistema debe permitir a los usuarios crear una cuenta proporcionando nombre, correo electrónico y contraseña. También el usuario puede elegir que tipo de cuenta quiere registrar, ya sea usuario regular o ser chef/Experto.

RF2 – Iniciar sesión
El sistema debe permitir el acceso al sitio web si las credenciales ingresadas coinciden con un usuario previamente registrado.

RF3 – Búsqueda de recetas  
El sistema debe permitir buscar recetas utilizando filtros como ingredientes, tipo de comida o dificultad.

RF4 – Guardar recetas  
El sistema debe permitir guardar recetas en colecciones personales.

RF5 – Crear recetas  
El sistema debe permitir a chefs o usuarios avanzados publicar recetas con ingredientes, pasos e imágenes.

RF6 - Listar recetas
El sistema debe permitir listar recetas previamente creadas y almacenada en el sistema.

RF7 - Editar recetas
El sistema debe permitir editar recetas previamente creadas y almacenada en el sistema.
