# Requerimientos No Funcionales

RNF1 – Rendimiento  
El sistema debe mostrar los resultados de búsqueda de manera inmediata sin recargar la página innecesariamente.

RNF2 – Seguridad  
El sistema debe requerir inicio de sesión para crear, modificar o guardar recetas.

RNF3 – Accesibilidad  
La plataforma debe usar colores con buen contraste, texto legible y permitir navegación mediante teclado, cumpliendo nivel AA de WCAG 2.1.

RNF4 – Disponibilidad  
El sistema debe funcionar correctamente en navegadores modernos como por ejemplo en Chrome.

RNF5 – Usabilidad  
El usuario debe poder acceder a cualquier receta desde la página principal en máximo 3 pasos.
